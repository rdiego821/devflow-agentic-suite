# 📚 Glosario SDLC & Agentic Engineering

| Término | Definición | Uso en el Proyecto |
| :--- | :--- | :--- |
| **SDLC** | Software Development Life Cycle. A structured process for planning, designing, building, and testing software. | Guides project modules from start to finish. |
| **MCP (Model Context Protocol)** | Standard protocol for connecting LLMs with local data sources and tools. | Enables the AI ​​to inspect a Java project and execute Git commands. |
| **Clean Architecture** | Architecture that separates the business domain from technical details and frameworks. | Ensures that the generated Java code is modular and testable. |
| **AST (Abstract Syntax Tree)** | Tree representation of the source code's syntactic structure. | Used to validate that the Java code generated by the AI ​​is syntactically correct. |
| **Agentic Tooling** | AI-powered tools that execute decisions autonomously, with oversight. | Automates the creation of JUnit tests and REST controller scaffolding. |
