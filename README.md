# 🚀 DevFlow Agentic Suite

Modular platform for the agentic automation of the **SDLC** (Software Development Life Cycle), designed to integrate intelligence capabilities Artificial en flujos de desarrollo backend en **Java / Spring Boot**, análisis de código local vía **MCP Server (Python)** y una interfaz interactiva en **React & TypeScript**.

## 🏗️ Monorepo Architecture

```text
devflow-agentic-suite/
├── docs/                             # Architecture diagrams and glossary
├── mcp-server-python/                # MCP server for local context and tools
├── spring-boot-generator-engine/     # Java code and JUnit test generator
└── frontend/                         # Dashboard UI in React + Vite
